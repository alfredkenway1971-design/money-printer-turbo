# Money Printer Turbo — Web App

## Environment Variables

```env
# Required: OpenRouter API Key
OPENROUTER_API_KEY=sk-or-v1-...

# Optional: Custom OpenRouter model
OPENROUTER_MODEL=qwen/qwen3-8b-chat
```

## Setup

```bash
npm install
npm run dev
```

Visit `http://localhost:3000` to use the app.
